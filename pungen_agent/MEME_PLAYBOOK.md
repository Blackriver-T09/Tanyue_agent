# PunGen Agent Meme Playbook

This playbook lists demo-ready memes that are especially stageable with a robot
arm. Prefer memes with visible gestures, props, rhythm, or emotional beats.

## Suggested 60-Second Demo Script

1. Player: `棒棒糖`
   - Beat: `green_tea_grievance`
   - Robot: 捂脸转身，台词“你怎么能这样对 giegie”

2. Player: `龙王你怎么能这样对 giegie`
   - Beat: `green_tea_grievance`
   - Robot: 继续委屈，情绪状态累积

3. Player: `你要不要听听你在说什么`
   - Beat: `confusion_callout`
   - Robot: 疑惑扫视，停顿回指

4. Player: `退退退，别过来`
   - Beat: `boundary_rejection`
   - Robot: 连续摆手驱离

5. Player: `如何呢，又能怎`
   - Beat: `resigned_shrug`
   - Robot: 摊手挥退，进入无奈节奏

6. Player: `这一波必须致敬`
   - Beat: `respect_payoff`
   - Robot: 定格致敬，结束演示

## Selection Rule

For the hackathon demo, prioritize memes that satisfy at least two of:

- A visible prop or visual cue.
- A gesture the robot arm can perform safely.
- A clear emotional state.
- A short trigger phrase.
- A natural place in a Dragon King short-drama scene.
